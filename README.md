2. 🏏 Bat, Ball, Stumps Game
Description: An interactive mini-game inspired by classic hand cricket, built with custom state management to track match statistics.

Key Features:

Visual selection buttons for Bat, Ball, and Stumps.

Live score tracking displaying wins, losses, and ties (No. of matches win:1, lost:2, tie:2).

Reset functionality to clear match records.

3. ✅ Todo App
Description: A sleek task-management productivity application designed to organize daily chores and study goals with integrated due dates.

Key Features:

Dynamic task input field alongside a built-in date picker (dd-mm-yyyy).

Scrollable container supporting multiple active tasks with individual target dates.

Individual item deletion capabilities via dedicated action buttons.
